  このシステムでできること
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  社宅入居申請のヒアリングフォーム回答（Excel）と
  ヒアリングメール（Gmail）を組み合わせて、

    ① 勤務地・家賃上限を自動で紐付け
    ② ATBB・東建・D-Room・レオパレス・リアブロの
       5サイトから物件を一括検索
    ③ 各物件の詳細PDF＋通勤地図を自動取得
    ④ 「進捗ID_氏名」フォルダに整理して保存

  します。

  ┌──────────────────────────────────────────────────────────────┐
  │  ③起動する.bat → ブラウザでメール貼り付け＋Excel アップロード  │
  │                → 「実行する」クリック → 完成！                │
  └──────────────────────────────────────────────────────────────┘

  初回セットアップ（初めて使うときだけ）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ Gmail認証ファイルの設置
  ─────────────────────────

  ヒアリングメールの就業先住所を自動取得するために
  Gmail API の認証ファイルが必要です。

  【手順】
  1. ブラウザで Google Cloud Console を開く
       https://console.cloud.google.com/

  2. プロジェクトを作成（例：「社宅システム」）
       画面上部の「プロジェクト選択」→「新しいプロジェクト」

  3. Gmail API を有効にする
       左メニュー「APIとサービス」→「ライブラリ」→
       「Gmail API」を検索 →「有効にする」をクリック

  4. OAuth 同意画面を設定する
       「APIとサービス」→「OAuth同意画面」→
       ユーザーの種類「外部」→「作成」
       アプリ名：社宅システム（何でもOK）
       サポートメール：自分のGmailアドレス
       →「保存して次へ」を3回クリック →「ダッシュボードに戻る」

  5. OAuth クライアントIDを作成する
       「APIとサービス」→「認証情報」→「認証情報を作成」
       →「OAuthクライアントID」
       アプリケーションの種類：「デスクトップアプリ」
       名前：社宅システム（何でもOK）
       →「作成」→「JSONをダウンロード」

  6. ダウンロードしたJSONファイルを
       システムファイル/credentials.json
       という名前に変更して配置する

  7. pipeline.py を初回実行すると自動でブラウザが開き
     「このアプリはGmailへのアクセスを要求しています」
     と表示される → 自分のGmailアカウントでログインして「許可」
     → 以降は token.json が自動生成されてログイン不要になる

  ★ credentials.json が未設置の場合でも動作はします。
    その場合「Gmail取得をスキップします」と表示され、
    勤務地住所はスプレッドシートの記載値を使います。


  ◆ 家賃上限規程の確認・修正
  ───────────────────────────

  システムファイル/config/company_rules.json を開いて
  会社の規程書と照合してください。

  確認ポイント：
  ・A地域（東京都・大阪府など）に含まれる都道府県のリスト
  ・B地域に含まれる都道府県のリスト
  ・単身・2人入居・家族（3人）・家族（4人以上）の各家賃上限

  ※ 規程書（⑨新旧規程対照表.pdf）と照合して修正してください。
  ※ JSON形式のため、カンマや括弧を崩さないよう注意してください。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Gmail を使わずにメール本文をコピペして使う方法（推奨）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  credentials.json が不要なもっとも手軽な方法です。
  メール本文を「メール貼り付け.txt」に貼るだけで、
  勤務地住所・最寄り駅・家賃上限などが自動で読み取られます。

  ─────────────────────────────────────────────────────
  【手順 1】「メール貼り付け.txt」を開く
  ─────────────────────────────────────────────────────

  syataku.com フォルダ直下にある「メール貼り付け.txt」を
  メモ帳などで開いてください。

    場所：C:\Users\（ユーザー名）\Desktop\syataku.com\メール貼り付け.txt


  ─────────────────────────────────────────────────────
  【手順 2】メール本文を貼り付ける
  ─────────────────────────────────────────────────────

  ヒアリングメール（「部屋探し依頼」の通知メール）の本文を
  ファイルの末尾にそのまま貼り付けてください。

  貼り付けるメールの例：
  ┌─────────────────────────────────────────────────────────┐
  │進捗ID: 74377                                            │
  │グループ: 関東第二営業部 つくばG                          │
  │...（中略）...                                           │
  │企業名: マグ・イゾベール株式会社                          │
  │所在地: 〒315-8518 茨城県 かすみがうら市上稲吉2046番地１号 │
  │就業開始日: 2026年7月1日（水）                            │
  │通勤方法: 自転車 バス                                    │
  │社宅条件その他: 家具付き                                  │
  └─────────────────────────────────────────────────────────┘

  ★ 「進捗ID:」が含まれていることが必須です。
  ★ 「所在地:」が2行ある場合、後の方（企業の所在地）が
    就業先住所として使われます。

  ◆ 複数件まとめて貼り付けたい場合
    メールとメールの間を「========」（= を8個以上）で区切ってください：

    ...1件目のメール本文...

    ========

    ...2件目のメール本文...

  貼り付けたらファイルを上書き保存して閉じてください。


  ─────────────────────────────────────────────────────
  【手順 3】「①実行する.bat」をダブルクリックして実行
  ─────────────────────────────────────────────────────

  「メール貼り付け.txt」にメールが入っていると、
  システムが自動でそのファイルを優先して読み込みます。
  Gmail の credentials.json は不要です。

  ▼ 優先順位（自動で切り替わります）
    ① メール貼り付け.txt が入力済み → そのファイルを使う
    ② credentials.json がある       → Gmail API から取得
    ③ どちらもない                  → メール情報なしで実行

  ▼ 処理が終わったら
    「メール貼り付け.txt」の内容を削除してファイルを空にしておいて
    ください（次回実行時に前の内容が残らないようにするため）。


  ─────────────────────────────────────────────────────
  【補足】完成版スプレッドシートに直接入力する方法
  ─────────────────────────────────────────────────────

  メール本文がない場合や一部の項目だけ修正したい場合は、
  スプレッドシートに直接入力することもできます。

  手順：
  1. フォーム回答 Excel を置いた状態で以下を実行：
       python システムファイル\pipeline.py --dry-run --no-gmail

  2. 生成された「_完成版_日付_時刻.xlsx」を Excel で開き、
     以下の列に値を入力して保存：

  ┌──────────────────┬────────────┬───────────────────────────────────────┐
  │ 列名               │ 必須/任意  │ 記入例・注意事項                       │
  ├──────────────────┼────────────┼───────────────────────────────────────┤
  │ 勤務地住所         │ ★ 必須     │ 茨城県 かすみがうら市上稲吉2046番地１号│
  │                    │            │ → 必ず都道府県名から書いてください     │
  ├──────────────────┼────────────┼───────────────────────────────────────┤
  │ 最寄り駅           │ 任意       │ 例：石岡駅                             │
  ├──────────────────┼────────────┼───────────────────────────────────────┤
  │ 家賃上限（円）     │ 任意       │ 例：70000（空白なら規程書から自動計算）│
  ├──────────────────┼────────────┼───────────────────────────────────────┤
  │ 通勤方法_依頼      │ 任意       │ 例：自転車                             │
  ├──────────────────┼────────────┼───────────────────────────────────────┤
  │ 社宅条件           │ 任意       │ 例：家具付き                           │
  └──────────────────┴────────────┴───────────────────────────────────────┘

  3. 以下で実行（--no-gmail でスプレッドシートの値をそのまま使う）：
       python システムファイル\pipeline.py --no-gmail

  毎回の使い方（通常手順）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【手順 1】フォーム回答 Excel を用意する
  ────────────────────────────────────────

  Googleフォームの「回答」タブから Excel（.xlsx）をダウンロードし、
  「入力データ」フォルダに置いてください。

    場所：C:\Users\（ユーザー名）\Desktop\syataku.com\入力データ\
    ファイル名例：株式会社○○ 社宅利用ヒアリングフォーム （回答）.xlsx

  ★ 注意点
  ・「入力データ」フォルダに置くだけで自動認識されます
  ・「完成版」サブフォルダの中のファイルは入力として読み込まれません
  ・ファイル名が「テンプレート」で始まるものは自動でスキップされます
  ・複数の .xlsx がある場合は最後に更新したものが読まれます
  ・Excel を開いたまま実行するとエラーになります。必ず閉じてください


  【手順 2】「①実行する.bat」をダブルクリックする
  ──────────────────────────────────────────────────

  黒い画面（コマンドプロンプト）が開いて自動処理が始まります。

  処理の流れ：
    Step 1：フォーム回答 Excel を読み込む
    Step 2：Gmail から就業先住所・通勤方法などを取得
    Step 3：家賃上限を規程書（company_rules.json）と照合
    Step 4：検索パラメータを生成
    Step 5：完成版スプレッドシートを保存
    Step 6：全ケースの物件検索を実行
    Step 7：スプレッドシートにステータスを反映

  ⚠ 処理中はパソコンを操作しないでください
  ⚠ ブラウザが自動で開閉されます。閉じないでください
  ⚠ 1件あたり約3〜8分かかります（物件数による）


  【手順 3】完了を確認する
  ────────────────────────

  「完了しました！」と表示されたら処理終了です。

  ■ 物件PDFの確認場所：
    出力PDF / 案件ID_氏名 / のフォルダ内

    例：出力PDF/161291_田中太郎/
          161291_田中太郎_提案書_田中太郎.pdf
          161291_田中太郎_ATBB_○○マンション_地図付き.pdf
          161291_田中太郎_東建_○○アパート_地図付き.pdf
          161291_田中太郎_リアプロ_○○荘_地図付き.pdf

  ■ 完成版スプレッドシートの確認場所：
    入力データ / 完成版 / フォルダ内
    「元のファイル名_完成版_日付_時刻.xlsx」として保存されます。
    このファイルには勤務地・案件ID・家賃上限・検索ステータスが追記されています。

  ■ 処理済み入力 Excel の行き先：
    処理完了後、入力 Excel は自動で「入力データ/完成版/」へ移動されます。
    → 「入力データ/」は常にクリーンな状態を保ちます
    → 次の Excel をそのまま置くだけで次回実行できます

  夜間・自動実行する方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  「②自動実行する.bat」を使うと、確認プロンプトが一切出ずに
  処理が完了したら自動終了します。タスクスケジューラや
  夜間バッチ処理に適しています。

  ◆ 手動で自動モード実行する場合
    ①実行する.bat に --auto オプションを付けて実行します:
      ①実行する.bat --auto

  ◆ Windowsタスクスケジューラで定期実行する場合
    【設定手順】
    1. スタートメニュー →「タスクスケジューラ」を検索して開く
    2. 右側「基本タスクの作成」をクリック
    3. 名前：「社宅物件提案書 自動生成」
    4. トリガー：毎日・週次など希望の時刻を設定
    5. 操作：「プログラムの開始」を選択
    6. プログラム/スクリプト：
         C:\Users\（ユーザー名）\Desktop\syataku.com\②自動実行する.bat
    7. 「完了」をクリック

  ◆ ログの確認場所
    システムファイル\logs\ フォルダに
    「実行ログ_日付_時刻.txt」として保存されます。
    エラーが発生した場合はこのファイルを確認してください。

  ★ 自動実行前に必ず確認すること
    ・「メール貼り付け.txt」に今回のメール情報が入っているか
    ・「入力データ/」に今回の Excel が入っているか
    ・前回の実行が完了しているか（処理中に重複起動しない）

  ブラウザ Web UI を使う方法（③起動する.bat）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  コマンドプロンプトを使わずにブラウザだけで操作できる
  Web インターフェースが利用できます。

  ┌────────────────────────────────────────────────────┐
  │  ③起動する.bat をダブルクリック → ブラウザが自動で開く  │
  └────────────────────────────────────────────────────┘

  ◆ 起動手順
  ──────────────────────────────────────────────────────
  1. 「③起動する.bat」をダブルクリックする
     ・初回のみ Streamlit（画面表示用ライブラリ）が自動でインストールされます
       （2〜3分かかります。インターネット接続が必要です）
     ・2回目以降は数秒でブラウザが開きます

  2. ブラウザで http://localhost:8501 が自動で開く
     ・自動で開かない場合はアドレスバーに手動で入力してください

  3. ブラウザを閉じてもOKです。「③起動する.bat」の黒い画面を
     閉じるとサーバーも終了します。


  ◆ Web UI の使い方
  ──────────────────────────────────────────────────────

  画面の左半分：メール本文の貼り付け
  ┌──────────────────────────────────────────────────────┐
  │  ① ヒアリングメールの本文を貼り付ける                  │
  │  ┌───────────────────────────────────────────────┐   │
  │  │ ここにメール本文をそのまま貼り付けてください。  │   │
  │  │                                                 │   │
  │  │ 進捗ID: 74377                                   │   │
  │  │ 企業名: ○○株式会社                              │   │
  │  │ ...                                             │   │
  │  └───────────────────────────────────────────────┘   │
  │  ✅ 読み取り内容（案件ID・企業名・就業先 が表示される） │
  └──────────────────────────────────────────────────────┘

  画面の右半分：Excel ファイルのアップロード
  ┌──────────────────────────────────────────────────────┐
  │  ② ヒアリングフォームの Excel をアップロード           │
  │  ┌───────────────────────────────────────────────┐   │
  │  │ ここにファイルをドロップするか、ボタンで選択    │   │
  │  └───────────────────────────────────────────────┘   │
  │  ・すでに「入力データ」フォルダにある場合は             │
  │    アップロード不要（自動認識されます）                 │
  └──────────────────────────────────────────────────────┘

  オプション（必要な場合のみ）：
    ・特定の進捗IDのみ処理 → ID を入力（空白なら全件）
    ・ドライラン → チェックすると物件検索せずスプレッドシート更新のみ

  実行ボタン：
    ・メール本文と Excel の両方が揃ったら「🚀 実行する」ボタンが有効になる
    ・クリックすると処理が始まり、ログがリアルタイムで画面に表示される
    ・完了後、生成された PDF ファイルの一覧が画面に表示される

  特定の件だけ実行したいとき（コマンドオプション）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  通常は「①実行する.bat」をダブルクリックするだけで全件処理されます。
  特定の件だけ処理したいときは、コマンドプロンプト（黒い画面）を開いて
  以下のコマンドを入力してください。

  ■ 準備：
    コマンドプロンプトで syataku.com フォルダに移動する
      cd /d C:\Users\（ユーザー名）\Desktop\syataku.com

  ■ 特定の進捗IDだけ実行：
    python システムファイル\pipeline.py --id 74377

    複数指定：
    python システムファイル\pipeline.py --id 74377 74378 74379

  ■ Excelファイルのパスを直接指定：
    python システムファイル\pipeline.py --xlsx "C:\Users\...\回答.xlsx"

  ■ 検索せずスプレッドシートの更新だけ行う（確認用）：
    python システムファイル\pipeline.py --dry-run

  ■ Gmail取得をスキップ（勤務地が既にシートにある場合）：
    python システムファイル\pipeline.py --no-gmail

  ■ 複数オプションを組み合わせる例：
    python システムファイル\pipeline.py --id 74377 --no-gmail

  Gmailのヒアリングメールについて
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  システムは「社宅」という件名のメールを Gmail から自動取得します。
  以下の情報が読み取られます：

    ・進捗ID（フォーム回答と紐付けに使用）
    ・就業先住所  → 「勤務地住所」列に書き込み
    ・最寄り駅    → 「最寄り駅」列に書き込み
    ・企業名      → 「企業名」列に書き込み
    ・就業開始日  → 「就業開始日」列に書き込み
    ・通勤方法    → 「通勤方法_依頼」列に書き込み
    ・依頼上限賃料 → 「家賃上限（円）」列に書き込み（記載がある場合）
    ・社宅条件    → 「社宅条件」列に書き込み（家具付き等）

  ★ ヒアリングメールに「就業先住所」が記載されていることが重要です。
    就業先住所から「どの都道府県か」を判定して、
    エリア区分（A地域/B地域）と家賃上限を自動計算します。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  家賃上限の計算ロジック
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  以下の優先順位で家賃上限が決まります：

  ① メールに「依頼上限賃料」が記載されている場合
     → その金額を使用（規程書より優先）

  ② メールに記載がない場合
     → 就業先住所の都道府県でエリア区分を判定
     → 入居形態（単身/2人入居/家族3人/家族4人以上）と照合
     → company_rules.json の金額を使用

  エリア区分（company_rules.json で設定）：
    A地域：東京都・神奈川県・埼玉県・千葉県・大阪府・愛知県・兵庫県・
           京都府・福岡県・北海道
    B地域：茨城県・栃木県・宮城県・新潟県・長野県・静岡県・岐阜県 等
    その他：上記以外の都道府県

  家賃上限の例（現在の設定）：
    単身     A地域: 80,000円 / B地域: 70,000円 / その他: 60,000円
    2人入居  A地域:100,000円 / B地域: 90,000円 / その他: 70,000円
    家族3人  A地域:100,000円 / B地域: 90,000円 / その他: 80,000円

  ★ 規程書が変わったら company_rules.json を更新してください。

  よくある質問・トラブル対応
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q. Gmail が取得されず「credentials.json が見つかりません」と表示される
  A. 初回セットアップの手順で credentials.json を設置してください。
     設置後に再実行するとブラウザでGoogleログインが求められます。
     「許可」するとその後は自動ログインになります。

  Q. 特定のサイトで 0件 になる
  A. そのエリアに物件がない場合と、検索条件が合わない場合があります。
     ・家賃上限が低すぎる → company_rules.json の金額を確認
     ・市区町村名が正しく取れていない → Gmailの住所形式を確認
     →「--dry-run」で完成版スプレッドシートを確認して「希望エリア」列を見てください

  Q. 「ATBB: 他セッション検出 → 強制ログイン処理」と表示される
  A. 別のブラウザやPCでATBBにログイン中の状態です。
     システムが自動で強制ログインするので特に操作は不要です。

  Q. 検索が途中で止まる・ブラウザが固まる
  A. Ctrl + C で中断して再実行してください。
     特定の進捗IDだけ処理したい場合は「--id 進捗ID」オプションを使ってください。

  Q. 「Pythonが見つかりません」と表示される
  A. Python 3.9以上をインストールしてください。
     https://www.python.org/downloads/
     インストール時に「Add Python to PATH」にチェックを入れてください。

  Q. 出力PDFフォルダにフォルダが作られているが中身が空
  A. 物件検索は成功したが PDF のダウンロードに失敗した可能性があります。
     黒い画面のログに「⚠」マークのエラーが出ていないか確認してください。

  Q. スプレッドシートを開いたまま実行してしまった
  A. Excel を完全に閉じてから再実行してください。
     「~$ファイル名.xlsx」という隠しファイルが残っている場合も削除してください。

  Q. 「進捗ID」列が空白の行がある
  A. 進捗IDがない行は処理されません。フォーム回答に進捗IDが
     正しく入力されているか確認してください。

  Q. 完成版スプレッドシートが何個もできてしまった
  A. 実行のたびに「_完成版_日付_時刻.xlsx」が作成されます。
     最新のもの（ファイル名の末尾の日時が最新のもの）以外は
     削除していただいて構いません。
